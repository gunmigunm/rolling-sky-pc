# 滚动的天空 · PC 版（Windows 免安装）

原版《滚动的天空》在 Windows 上直接双击开玩：不用安卓模拟器、不用管理员权限、无广告无内购，自带 41 个官方关卡与全部 BGM，并附带一个自动游玩 Bot（实验）。

完整成品包（515MB，含 41 首离线音乐）在百度网盘：见仓库说明或本文末尾。

## 工作原理

原版 APK 是 Unity 2017.4 + IL2CPP + arm64，Windows 上没有能直接跑它的原生运行时；把关卡密文解出来还要啃 FairGuard/AES。

所以走的是**社区已验证的原版资源还原 + 自建 PC 外壳**：

1. 游戏本体用开源还原工程 [`3kh0/rolling-sky`](https://github.com/3kh0/rolling-sky)（Rolling Sky Unleashed）：它的玩法代码由 ILSpy 从旧版 Mono APK 反编译恢复，关卡地图用 sqdldev 的 Level Encryptor 解出，美术与音乐来自原版资产导出，并用 Unity 2017.4 重建为 WebGL 构建。
2. 本仓库的 `launcher.cs` 是自写的 8KB 启动器：随机端口起一个只监听 `127.0.0.1` 的静态服务（自实现的最小 HTTP），再用 Edge 的 `--app` 无边框窗口打开游戏。不装任何依赖，不用管理员。
3. `bot.js` 注入到页面里，做三件事：把方向键/空格翻译成游戏要的鼠标事件、定时自动点按跳跃、可选地用画面最亮连续段做一次简易避障。为了让 Bot 能读画面，注入脚本在 Unity 创建 WebGL 上下文时强制打开 `preserveDrawingBuffer`。

## 目录

```
滚动的天空PC/
├─ 滚动的天空.exe        # 自写启动器（C# 编译，8KB）
├─ 使用说明.txt
├─ game/
│  ├─ index.html        # 注入了 bot.js 的页面
│  ├─ bot.js
│  ├─ web/Build/        # Unity WebGL 构建（44MB 数据 + 6MB wasm）
│  └─ assets/music/      # 41 首 BGM
```

## 键位

| 操作 | 键 |
|---|---|
| 跳 | `空格` / 鼠标点一下 |

| 自动游玩 | `F8` |

## 从源码重建

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

脚本会下载 WebGL 构建与 41 首音乐、编译启动器、组装出可直接双击的目录。
